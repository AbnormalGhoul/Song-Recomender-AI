## Dataset
- **Compressed:** https://www.kaggle.com/datasets/ryanholbrook/the-million-songs-dataset
- **Full:** http://millionsongdataset.com/

## Setup & Quickstart

1. Place your downloaded Kaggle dataset inside the `data/` folder
2. Run the startup script:
```bash
chmod +x start.sh
./start.sh
```
